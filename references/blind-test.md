# Слепой тест

Цель — проверить экран глазами того, кто не знает брифа. Агент, который делал экран, для этого не годится: он видит то, что задумал.

## Как запускать

Субагент (Agent tool) получает только путь к PNG пикового экрана. Ни брифа, ни названия, ни ядра, ни этого файла. Если субагентов нет — пропустить тест и честно написать об этом.

Промпт субагенту, дословно:

```
Открой картинку <путь> через Read. Это экран мобильного приложения. Ответь коротко, по строке на пункт:
1. Что это за продукт и что он делает?
2. Для кого он?
3. Три слова: какое ощущение от экрана?
4. Что на экране главное, куда смотришь первым?
5. Что здесь есть такого, чего нет в других приложениях этого типа? Если ничего — так и скажи.
6. На какое известное приложение это похоже?
```

## Как читать ответы

Сверить с брифом:
- п.1–2 мимо продукта или аудитории — экран не объясняет себя, проблема в идее, не в стиле;
- п.3 совпало с анти-чувством — переделать направление;
- п.4 назван не герой из концепта — переставить иерархию;
- п.5 «ничего» или п.6 назвал конкурента из шаблона ниши — шаблон, вернуться к стоп-листу проекта.

Тест прошёл, когда п.1, 3 и 4 совпадают с брифом, а п.5 называет что-то из ядра.

Второй вариант теста — тот же экран без текстов (п.1 и 4): отрендерить с `* { color: transparent !important; }` или заменить строки на серые плашки. Если без текстов непонятно, что делает экран, визуальной идеи нет.

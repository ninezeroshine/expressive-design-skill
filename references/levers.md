# Рычаги

Брать 2–3, к каждому — метрика и строка ядра, из которой он вырос.

| Рычаг | Работает на | Риск |
|---|---|---|
| Маскот с поведением (реагирует, меняет форму) | удержание, мягкий пейвол | наклейка без поведения; тормоза |
| Фирменный контрол (дуга под палец, «налей», колесо) | активация, «хочется показать» | непонятен без подсказки; нужна обычная альтернатива |
| Типографика как голос | первое впечатление, премиальность | читаемость |
| Цвет как идентичность (один цвет или цвет по состоянию) | узнаваемость | контраст, тёмная тема |
| Материал (стекло, желе, глина, зерно) | тактильность, премиум | вес; «как у всех AI-стартапов» |
| Геймификация (стрик, путь, XP) | удержание | давит, если не связана с ценностью |
| Голос в тексте | доверие, симпатия | кринж мимо аудитории |
| Juice (пружины, частицы, хаптика) | ощущение качества, пик | утомляет, если везде |

Деньги, здоровье, кризис — без маскота и юмора: характер через материал, типографику, тон.

## Бюджет

Громко: первый экран, онбординг, первая победа, успех. Громко, но цена ясна: пейвол. Средне: пусто, ошибка. Тихо: списки, формы, настройки.

## Тесты на шаблонность

1. Закрыть логотип — понятно, чей продукт?
2. Подменить продукт — экран подойдёт конкуренту?
3. Закрыть тексты — понятно, что делает экран?
4. Один герой на экране или пять равных?

Стоп-лист по умолчанию: фиолетово-синий «AI»-градиент, сетка одинаковых карточек как единственная идея, 3D-капля без связи с продуктом, стоковые люди, кремовый/off-white фон, курсивные акцентные слова, моноширинные лейблы, кнопки-таблетки.

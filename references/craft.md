# Ремесло

## Цвет
Токены по роли (`bg`, `surface`, `text`, `text-muted`, `border`, `accent`, `on-accent`, `danger`…), в OKLCH: оттенки — сменой L и C при том же H. Тёмная тема — переназначение ролей, не инверсия. Контраст: текст ≥ 4.5:1, крупное и контролы ≥ 3:1. Один акцент на экран.

## Движение
| Что | Значение |
|---|---|
| Отклик на касание | < 100 мс, scale 0.96–0.98 |
| Мелкий переход | 150–250 мс |
| Экран, лист, модалка | 300–450 мс |
| Празднование | до ~800 мс, только на пиках |
| Пружина рабочего UI | bounce ≤ 0.15 |
| Пружина контрола и маскота | bounce 0.25–0.4 |

Вход ease-out, выход ease-in. Пружины, а не keyframes: анимация прерываема с текущей скорости. Жест 1:1 за пальцем, после отпускания доезжает и магнитится. Анимировать `transform` и `opacity`. Reduce Motion: перемещения убрать, смену состояний оставить.

## Состояния
Контрол: обычный, нажат, фокус, неактивен, загрузка. Экран: пусто, загрузка (до 300 мс ничего, потом скелет), ошибка (что случилось + что делать + кнопка), успех. Цель касания ≥ 44 pt.

## Маскот
Форма из ядра продукта, не «милое существо». Один SVG-компонент с параметрами `mood`, `skin`, `size`. Состояния = события продукта (покой, думает, верно, почти, празднует, спит). Жизнь дают детали: объём и тень у каждой части, крупные глаза с бликом, зрачки смотрят по действию, мимика линиями с обводкой, тень на земле. Перед вставкой в экраны — отрендерить лист всех состояний и посмотреть. CSS-прямоугольники вместо SVG выглядят плохо, проверено.

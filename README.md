# expressive-design

Claude skill: интерфейс с характером, выведенный из ядра продукта и бизнес-метрики, а не из шаблона.

Установка: положить папку в каталог скиллов или собрать архив `zip -r expressive-design.skill expressive-design`.

- `SKILL.md` — процесс из 8 шагов
- `references/levers.md` — рычаги, бюджет, тесты на шаблонность, стоп-лист
- `references/craft.md` — цвет, движение, состояния, маскот
- `references/blind-test.md` — слепой тест экрана субагентом
- `references/gallery/` — референсы по рычагам (пополняется)
